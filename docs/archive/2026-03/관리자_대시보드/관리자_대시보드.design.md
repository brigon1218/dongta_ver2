# 관리자_대시보드 — Design 문서

**Feature**: 관리자_대시보드  
**Phase**: Design  
**Date**: 2026-03-31  
**Architecture**: Option C — 템플릿 Override

---

## Context Anchor

| 항목 | 내용 |
|------|------|
| **WHY** | 운영 효율화 — 파편화된 모니터링/관리 도구를 Django Admin 하나로 통합 |
| **WHO** | is_staff=True 관리자 계정 |
| **RISK** | monitoring API 응답 지연 시 대시보드 느려질 수 있음 |
| **SUCCESS** | `/admin/` 접속 시 통계 카드 4개 표시, 모든 앱 모델 Admin 관리 가능 |
| **SCOPE** | Django Admin 템플릿 오버라이드 + Stats View. 별도 프론트엔드 없음. |

## 1. 아키텍처 개요

### 1.1 선택: Option C — 템플릿 Override

```
[관리자 브라우저]
      │
      ▼
GET /admin/  →  Django Admin (기본)
                    │
                    ▼
         templates/admin/index.html  ← 커스텀 오버라이드
                    │
                    ├── AJAX GET /admin/dashboard-stats/
                    │         │
                    │         ▼
                    │   AdminDashboardStatsView
                    │   (Django ORM + monitoring API 집계)
                    │         │
                    │         ▼
                    │   JSON { users, businesses, payments, posts, system }
                    │
                    └── 통계 카드 4개 렌더링
```

### 1.2 기존 vs 변경

| 항목 | 기존 상태 | 변경 후 |
|------|-----------|---------|
| `admin/index.html` | Django 기본 | 통계 카드 추가 |
| `accounts/admin.py` | Member 등록됨 ✅ | 유지 |
| `board/admin.py` | Post/Comment 등록됨 ✅ | 신고 액션 추가 |
| `payment/admin.py` | PointAccount/PaymentHistory 등록됨 ✅ | 유지 |
| `business114/admin.py` | Business 등록됨 ✅ | 유지 |
| `monitoring/admin.py` | 비어있음 | EventSource 등록 추가 |
| `apps/core/views.py` | HealthCheck, Landing | AdminDashboardStatsView 추가 |
| `config/urls.py` | 기존 URL | `/admin/dashboard-stats/` 추가 |
| `templates/admin/` | 없음 | `index.html` 신규 |

## 2. 데이터 모델 (읽기 전용)

대시보드는 기존 모델을 읽기만 합니다. 신규 모델 없음.

| 앱 | 모델 | 집계 쿼리 |
|----|------|-----------|
| accounts | Member | `count()`, `filter(created_at__date=today).count()` |
| business114 | Business | `count()`, `filter(is_approved=False).count()` |
| payment | PaymentHistory | `filter(created_at__date=today).aggregate(Sum('amount'))` |
| board | Post | `count()`, `filter(created_at__date=today).count()` |
| monitoring | (API 호출) | `GET /api/v1/monitoring/status/` 내부 호출 |

## 4. 템플릿 설계

### 4.1 `templates/admin/index.html`

Django Admin의 `admin/index.html`을 오버라이드. 기존 앱 목록 위에 통계 카드 섹션 추가.

```html
{% extends "admin/base_site.html" %}

{% block content %}
<!-- 통계 카드 섹션 -->
<div id="dashboard-stats" style="...">
  <div class="stat-card" id="card-users">...</div>
  <div class="stat-card" id="card-businesses">...</div>
  <div class="stat-card" id="card-payments">...</div>
  <div class="stat-card" id="card-system">...</div>
</div>

<!-- 기존 Django Admin 앱 목록 (super() 호출) -->
{{ block.super }}

<script>
// 페이지 로드 시 stats API 호출
fetch('/admin/dashboard-stats/')
  .then(r => r.json())
  .then(data => renderCards(data));
</script>
{% endblock %}
```

## 5. Admin 개선 사항

### 5.1 board/admin.py — 신고 액션 추가

```python
@admin.register(Post)
class PostAdmin(admin.ModelAdmin):
    # 기존 설정 유지
    actions = ['hide_posts']

    def hide_posts(self, request, queryset):
        queryset.update(is_hidden=True)  # Post 모델에 is_hidden 필드 확인 필요
    hide_posts.short_description = "선택된 게시글 숨김 처리"
```

### 5.2 monitoring/admin.py — EventSource 등록

```python
from apps.sync.models import EventSource  # sync 앱의 이벤트 모델

@admin.register(EventSource)
class EventSourceAdmin(admin.ModelAdmin):
    list_display = ['id', 'source_type', 'status', 'created_at']
    list_filter = ['status', 'source_type']
    actions = ['retry_events']
```

## 6. 보안

| 항목 | 설계 |
|------|------|
| 대시보드 접근 | `request.user.is_staff` 확인 |
| Stats API | `@staff_member_required` 데코레이터 |
| CSRF | Django Admin 세션 쿠키 사용 (AJAX에 csrftoken 포함) |
| 민감 데이터 | 결제 금액 합계만 노출, 개별 TID 미노출 |

---

## 7. 에러 처리

| 상황 | 처리 방식 |
|------|-----------|
| Stats API 응답 지연 (>2초) | 타임아웃 후 카드에 "N/A" 표시 |
| monitoring API 실패 | system 카드에 "확인 불가" 표시, 나머지 카드는 정상 |
| DB 쿼리 실패 | 해당 카드만 "오류" 표시 |

---

## 8. 테스트 계획

| 테스트 | 방법 |
|--------|------|
| Stats API 응답 확인 | `GET /admin/dashboard-stats/` 직접 호출 |
| 통계 카드 렌더링 | 관리자 계정으로 `/admin/` 접속 |
| 비관리자 접근 차단 | 일반 계정으로 `/admin/dashboard-stats/` 접근 → 403 확인 |
| 게시글 숨김 액션 | Admin에서 게시글 선택 후 액션 실행 |
