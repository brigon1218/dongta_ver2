## 5. Lessons Learned

### 5.1 What Went Well

1. **명확한 설계 문서**: Plan, Design 문서의 상세함이 구현 단계에서 모호함을 최소화
2. **효율적인 PDCA 사이클**: 1회 반복으로 91% 달성 (5회 중 1회만 사용)
3. **크로스앱 데이터 통합**: 5개 앱의 데이터를 효율적으로 집계
4. **보안-우선 개선**: Rate Limiting, Soft Delete, atomic transaction 구현
5. **포괄적 테스트**: 9개 통합 테스트로 주요 시나리오 커버

### 5.2 Areas for Improvement

1. **ActivitySummary 응답 형식 불일치** (P2)
   - Design: `{ "counts": { ... } }`
   - Implementation: `{ "..._count": ... }`
   - Impact: Low (기능 동작 정상)

2. **비밀번호 변경 후 토큰 무효화** (P2)
   - JWT 토큰이 1시간 유효 (향후 보안 강화 가능)

3. **PasswordChangeView 중복** (P3)
   - accounts와 mypage에 동일 기능 구현
   - 향후 리팩토링 시 통합 권장

4. **테스트 커버리지 확대** (P3)
   - 현재 70%, 90%+ 목표로 추가 테스트 가능

### 5.3 To Apply Next Time

1. 설계 단계에서 보안 명시 (Rate Limiting, soft delete 등)
2. Gap Analysis 정확도 강화 (API 엔드포인트만 아닌 응답 형식, 보안, 테스트까지)
3. 테스트 우선 (TDD 가능성)
4. 크로스앱 의존성 명시적 문서화
5. PDCA 효율성 추적 및 메트릭 표준화
