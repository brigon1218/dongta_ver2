# 마이페이지(mypage) 모듈 고도화 Planning Document

> **Summary**: 사용자의 개인정보 관리, 포인트 이용 내역 조회 및 활동 내역 통합 관리를 위한 Django REST API 서비스 구축
>
> **Project**: dongta.com
> **Phase**: Phase 3 (모듈별 완전 전환)
> **Version**: 1.0.0
> **Author**: Team
> **Date**: 2026-03-07
> **Status**: Planning

---

## 1. Overview

### 1.1 Purpose

사용자가 자신의 개인정보를 안전하게 수정하고, 포인트 잔액 및 이용 내역을 투명하게 확인하며, 사이트 내에서의 모든 활동(게시글, 공고 등)을 한곳에서 관리할 수 있는 통합 마이페이지 기능을 제공한다.

### 1.2 Background

- **현황**: 회원 정보(`accounts`), 포인트(`payment`), 게시판(`board`), 채용(`recruit`) 등 각 모듈의 데이터는 준비되었으나, 이를 사용자 관점에서 모아 보여주는 인터페이스가 부재함.
- **목표**: 각 모듈의 API를 유기적으로 연결하여 통합된 사용자 경험 제공.

---

## 2. Scope

### 2.1 In Scope

- **프로필 관리**:
  - 회원 기본 정보(이름, 연락처, 주소 등) 조회 및 수정
  - 비밀번호 변경 기능
- **포인트 내역 관리**:
  - 현재 보유 포인트 잔액 조회
  - 충전 내역(PaymentHistory) 및 사용 내역 통합 조회 (필터링 지원)
- **활동 요약 (Dashboard)**:
  - 내가 작성한 게시글 수, 등록한 업체 수, 채용 공고 수 등 요약 정보
- **회원 탈퇴**:
  - 계정 비활성화(소프트 삭제) 처리

### 2.2 Out of Scope

- 프로필 이미지 크기 자동 최적화 (향후 Media 처리 과제)
- 소셜 계정 연동 관리 (별도 Phase)
- 포인트 선물하기 등 복잡한 포인트 트랜잭션 (현재는 충전/사용만)

## 3. Requirements

### 3.1 Functional Requirements

| ID | Requirement | Priority | Status |
|----|-------------|----------|--------|
| FR-01 | 회원 개인정보 조회 및 수정 API | High | Pending |
| FR-02 | 비밀번호 변경 API (현재 비번 검증 포함) | High | Pending |
| FR-03 | 포인트 충전 및 사용 내역 통합 조회 | High | Pending |
| FR-04 | 내 활동 요약 정보(카운트) 제공 | Medium | Pending |
| FR-05 | 회원 탈퇴(Soft Delete) 기능 | Medium | Pending |

### 3.2 Non-Functional Requirements

- **보안**: 정보 수정 및 포인트 조회 시 반드시 본인 인증(JWT) 필수.
- **성능**: 여러 모듈의 카운트 정보를 집계할 때 효율적인 쿼리 수행.
- **일관성**: 기존에 구현된 `core.utils`의 응답 형식을 준수.

---

## 4. Architecture

### 4.1 핵심 컴포넌트

- **Serializers**: `UserProfileSerializer`, `PasswordChangeSerializer`, `PointHistorySerializer`
- **Views**: `ProfileView`, `PointHistoryView`, `ActivitySummaryView`
- **Permissions**: `IsAuthenticated` (모든 기능에 적용)

---

## 5. Implementation Roadmap

1. **Step 1**: 회원 정보 수정 및 비밀번호 변경 API 구현
2. **Step 2**: 포인트 충전/사용 내역 통합 조회 API 구현
3. **Step 3**: 각 도메인별 활동 카운트 집계 로직 구현
4. **Step 4**: 회원 탈퇴 및 데이터 정리 로직 구현
5. **Step 5**: 최종 통합 테스트 및 완료 보고

---

## 6. Success Criteria

- 회원 정보 수정 시 `accounts_member` 테이블에 정확히 반영됨
- 비밀번호 변경 후 신규 비밀번호로 로그인이 가능함
- 포인트 내역이 충전/사용 구분 없이 최신순으로 잘 조회됨
- 일치율(Match Rate) 90% 이상 달성
