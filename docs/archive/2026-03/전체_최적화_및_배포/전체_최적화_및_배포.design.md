## 1. Performance Optimization Design

### 1.1 Database Indexing (PostgreSQL)
JSONField(`occupations`, `items`) 검색 성능을 극대화하기 위해 GIN(Generalized Inverted Index) 인덱스를 적용합니다.

- **대상 모델 및 필드**:
  - `recruit.JobNotice`: `occupations` (JSONField)
  - `business114.Business`: `items` (JSONField)
- **적용 방법**: `django.contrib.postgres.indexes.GinIndex`를 모델 Meta에 추가.

### 1.2 Caching Strategy (Redis)
자주 변하지 않으면서 조회가 빈번한 API에 캐싱을 적용합니다.

- **대상**:
  - 업체 카테고리/품목 리스트
  - 채용 공고 공통 코드 (고용형태 등)
- **도구**: `django.core.cache` (Redis Backend)

## 2. Production Infrastructure Tuning

### 2.1 Web Server (Nginx)
- **역할**: 리버스 프록시, 정적 파일 서빙, SSL 종단점.
- **최적화**:
  - `keepalive_timeout`: 65s
  - `gzip`: on (응답 압축)
  - `client_max_body_size`: 20M (이미지 업로드 대응)

### 2.2 Application Server (Gunicorn)
- **Worker 모델**: `gevent` 또는 `sync` (I/O 특성에 따라 선택)
- **Worker 수**: `(2 x CPU Cores) + 1` 권장.
- **Timeout**: 30s

## 3. CI/CD Pipeline Design (GitHub Actions)

### 3.1 Workflow 단계
1. **Lint & Test**: 코드 스타일 체크 및 `pytest` 실행.
2. **Build**: Docker 이미지 빌드 및 태깅 (SHA 기준).
3. **Push**: Docker Hub 또는 AWS ECR로 이미지 전송.
4. **Deploy**: 운영 서버 SSH 접속 -> `docker-compose.prod.yml` 실행.

### 3.2 Secrets Management
- `DATABASE_URL`, `SECRET_KEY`, `DANAL_CPID` 등 민감 정보는 GitHub Secrets에서 관리.

---

## 4. Monitoring & Logging

### 4.1 Sentry Integration
- **기능**: 실시간 런타임 에러 트래킹.
- **설정**: `sentry-sdk` 패키지 설치 및 `settings/production.py` 연동.

### 4.2 Logging Configuration
- **파일 로깅**: `TimedRotatingFileHandler`를 사용하여 로그 파일 날짜별 분리.
- **수준**: 운영 환경은 `INFO`, 에러는 `ERROR`.

---

## 5. Security Hardening

- **Rate Limiting**: `django-ratelimit`을 로그인 및 주요 등록 API에 적용 (IP당 요청 수 제한).
- **Security Headers**: `django-csp`, `django-security-headers` 적용 검토.
- **Allowed Hosts**: 운영 도메인만 허용.

---

## 6. Implementation Order

1. **Step 1**: DB 마이그레이션을 통한 GIN 인덱스 적용.
2. **Step 2**: 운영용 설정 파일(`settings/production.py`) 분리 및 환경변수 정비.
3. **Step 3**: Docker Compose 운영 프로파일(`docker-compose.prod.yml`) 작성.
4. **Step 4**: Sentry 연동 및 로깅 시스템 구축.
5. **Step 5**: CI/CD 워크플로우 파일(`.github/workflows/deploy.yml`) 작성 및 배포 테스트.
