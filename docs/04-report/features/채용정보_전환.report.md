## 1. Overview

### 1.1 Purpose

동타닷컴의 핵심 서비스인 채용 정보 시스템을 PHP 기반의 레거시에서 현대적인 Django REST API 기반으로 완전히 전환하여 모바일 및 웹 서비스의 확장성을 확보하고 보안을 강화함.

### 1.2 Accomplishments

- **API 현대화**: 기업(회사 정보, 채용 공고) 및 구직자(프로필, 이력서) 서비스를 위한 RESTful API 구축 완료
- **비즈니스 로직 이관**: 포인트 결제와 연동된 프리미엄 공고 신청 로직을 Django 서비스 레이어로 완벽히 이관
- **보안 강화**: 객체 수준 권한(Object-level Permissions) 적용으로 본인 데이터 보호 강화
- **검색 고도화**: JSONField를 활용한 다중 직종 검색 및 정렬 기능 구현
