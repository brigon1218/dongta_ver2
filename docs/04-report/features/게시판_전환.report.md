## 1. Overview

### 1.1 Purpose

분산되어 있던 PHP 레거시 게시판 데이터를 통합 관리할 수 있는 단일 `Post` 모델 기반의 Django API 시스템을 구축함. 권한 체계를 고도화하여 공지사항 보안을 강화하고, 현대적인 커뮤니티 기능을 위해 대댓글 및 추천 기능을 추가함.

### 1.2 Accomplishments

- **모델 통합**: 여러 게시판 테이블을 단일 `Post` 모델로 통합하고 `category`로 구분하여 확장성 확보
- **계층형 댓글**: 셀프 참조(Self-referencing) 구조를 통해 1단계 대댓글 기능을 Serializer 수준에서 구현
- **정밀한 권한 제어**: 공지사항(Staff Only), 자유게시판(Authenticated), 본인 글 수정(Owner) 등 세분화된 권한 적용
- **데이터 정합성**: 조회수 및 추천수 업데이트 시 `F` 객체를 활용하여 동시성 이슈를 원천 차단

### 2.1 Core Features
