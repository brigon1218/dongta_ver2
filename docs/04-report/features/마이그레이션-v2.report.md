### 4.2 API 엔드포인트 (완성)

#### 인증 API
```
POST   /api/accounts/register/      # 회원가입
POST   /api/accounts/login/         # 로그인
POST   /api/accounts/refresh/       # 토큰 갱신
GET    /api/accounts/profile/       # 프로필 조회
```

#### Business114 API
```
GET    /api/business114/search/     # 업체 검색
POST   /api/business114/create/     # 업체 등록
GET    /api/business114/{id}/       # 업체 상세 조회
PUT    /api/business114/{id}/       # 업체 정보 수정
DELETE /api/business114/{id}/       # 업체 삭제
```

#### Recruit API
```
GET    /api/recruit/jobs/           # 공고 목록
POST   /api/recruit/jobs/create/    # 공고 등록
GET    /api/recruit/jobs/{id}/      # 공고 상세
PUT    /api/recruit/jobs/{id}/      # 공고 수정
DELETE /api/recruit/jobs/{id}/      # 공고 삭제

GET    /api/recruit/resumes/        # 이력서 목록
POST   /api/recruit/resumes/        # 이력서 등록
PUT    /api/recruit/resumes/{id}/   # 이력서 수정
```

#### Payment API
```
GET    /api/payment/balance/        # 잔액 조회
POST   /api/payment/charge/         # 포인트 충전
GET    /api/payment/history/        # 결제 이력 조회
```

### 4.3 데이터베이스 설계

#### 핵심 테이블
- **accounts_customuser**: 통합 회원 모델 (JWT 토큰 관리)
- **business114_business**: 업체 정보 (정규화된 전화/주소)
- **business114_item**: 취급 품목 (JSON 형식)
- **recruit_job**: 채용 공고
- **recruit_resume**: 구직자 이력서
- **payment_point**: 포인트 잔액
- **payment_transaction**: 결제 이력

#### 보안 기능
- Soft Delete (논리적 삭제)
- 감사 로그 (created_at, updated_at)
- 암호화된 민감 정보 저장

### 4.4 인프라 구성

**Docker Compose 스택**:
```yaml
Services:
  - django:     Django REST Framework 백엔드 (포트 8000)
  - postgres:   PostgreSQL 데이터베이스 (포트 5432)
  - redis:      캐시 및 메시지 브로커 (포트 6379)
  - celery:     비동기 작업 처리
  - nginx:      리버스 프록시 (포트 80/443)
```

**환경 설정**:
- `DEBUG=False` (프로덕션)
- `ALLOWED_HOSTS` 설정
- `CSRF_COOKIE_HTTPONLY=True`
- `SECURE_SSL_REDIRECT=True`
- 데이터베이스 환경변수 분리
