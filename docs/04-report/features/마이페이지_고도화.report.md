## 1. Overview

### 1.1 Purpose

### 1.2 Accomplishments

- **통합 대시보드 구현**: `board`, `recruit`, `business114` 등 각 앱에 분산된 활동 데이터를 카운트하여 요약 제공하는 API 구축 완료
- **계정 보안 강화**: 비밀번호 변경 및 회원 탈퇴 시 현재 비밀번호 일치 여부를 검증하는 로직을 필수로 적용
- **포인트 투명성 확보**: 현재 잔액과 충전 내역을 실시간으로 결합하여 보여주는 통합 조회 API 구현
- **소프트 탈퇴 체계**: 데이터 무결성을 위해 계정 비활성화 및 `soft_delete`를 조합한 안전한 탈퇴 프로세스 정립
