## 1. Overview

### 1.1 Purpose

현재 운영 중인 dongta.com의 보안 취약점(MD5 해싱)을 해결하고, 신규 Django/PostgreSQL 시스템으로의 점진적 마이그레이션을 위한 데이터 동기화 기반을 마련함.

### 1.2 Accomplishments

- **보안 강화**: MD5 패스워드 해시를 Argon2id로 자동 업그레이드하는 체계 구축
- **데이터 정합성**: 회원, 업체, 채용, 결제 등 전 도메인 데이터 매핑 및 동기화 로직 완성
- **운영 안정성**: Celery Beat를 활용한 주기적 폴링 및 정합성 검증 태스크 구현

## 2. Implementation Details

### 2.1 Core Features

| Feature | Description | File Path |
|---------|-------------|-----------|
| **MD5 지원 해셔** | 레거시 `md5$hash` 검증 및 자동 업그레이드 | `apps/accounts/hashers.py` |
| **회원 동기화** | 12개 이상 누락 필드 보완 및 데이터 정규화 | `apps/sync/tasks.py` |

### 2.2 Key Technologies

- **Framework**: Django 4.2+, DRF 3.14+
- **Security**: Argon2id (via `argon2-cffi`), Custom Password Hasher
- **Async Task**: Celery 5.3+, Redis 5.0+
- **Database**: PostgreSQL (Master), MySQL (Legacy Source)
