# [Plan] 개발 환경 표준화 (맥/윈도우 동기화)

## 1. 개요
- **배경**: 집(macOS)과 사무실(Windows 11) 간의 터미널 환경 및 경로 설정 차이로 인한 개발 흐름 단절.
- **목표**: 어떤 OS에서든 동일한 명령어(`docker-compose` 등)와 설정으로 즉시 개발 가능한 환경 구축.

## 2. 현재 문제점 (Gap Analysis)
- **터미널**: Windows PowerShell/CMD vs macOS Zsh 간의 명령어 문법 차이.
- **경로**: Windows의 `` 구분자와 절대 경로 기반 시크릿 키 관리 문제.
- **실행 환경**: 로컬 Python 설치 여부에 따른 라이브러리 버전 불일치 가능성.

## 3. 해결 전략 (Strategy)
- **플랫폼 단일화**: Windows 11에 WSL2(Ubuntu)를 도입하여 macOS와 동일한 유닉스 기반 터미널 환경 사용.
- **경로 표준화**: `pathlib`과 환경 변수를 활용하여 시크릿 키 및 인증서 경로를 프로젝트 루트 기준 상대 경로로 통일.
- **워크플로우 표준화**: Docker를 기본 실행 환경으로 지정하여 호스트 OS의 영향을 최소화.

## 4. 주요 작업 항목 (Tasks)
### [Phase 1] Windows WSL2 최적화 가이드 작성 (Design 단계 포함)
- [ ] Windows Terminal + WSL2(Ubuntu) 설치 및 설정 방법 정리
- [ ] Docker Desktop WSL2 백엔드 연동 확인

### [Phase 2] 시크릿 키 및 경로 관리 표준화
- [ ] `.env` 파일 내 절대 경로를 상대 경로로 치환 가능하도록 `base.py` 수정
- [ ] Nginx용 Cloudflare 원본 인증서(SSL) 경로를 `config/nginx/ssl/`로 고정

### [Phase 3] 개발 편의성 도구 도입
- [ ] OS 독립적인 명령어 실행을 위한 `Makefile` 또는 헬퍼 스크립트 작성
