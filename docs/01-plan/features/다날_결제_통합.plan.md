## 1. Overview

### 1.1 Purpose

PHP 레거시의 다날(Danal) 결제 시스템을 Django REST API로 전환한다:

1. **다날 CPAY SDK 통합**: Django에서 직접 다날 결제 API를 호출
2. **이중 기록**: 결제 결과를 PostgreSQL(Django) + MySQL(레거시) 양쪽에 기록
3. **결제 방법**: 신용카드(Card) + 실시간 계좌이체(DirectBank) 지원
4. **보안 강화**: SQL Injection 제거, CSRF 보호, 서버 간 검증

### 1.2 Background

- **현재 상태**: Django payment 앱에 기본 모델/뷰 구현됨 (PointAccount, PaymentHistory, DanalReadyView, DanalCallbackView)
- **문제점**: DanalReadyView가 실제 다날 API를 호출하지 않음 (가짜 URL 반환)
- **레거시 분석**: PHP 다날 결제 코드에 SQL Injection 취약점 존재 (직접 문자열 보간)
- **Phase 2 성과**: Celery 동기화 파이프라인 완성 (`_process_payment_event` 핸들러 + MySQL 트리거)

### 1.3 Legacy Payment Flow Analysis

```
PHP 레거시 흐름 (현재):
  dongta_point_danal.php  (결제 폼)
      |
  danal/Card/Order.php    (주문 정보 → DongtaPointCharge INSERT)
      |
  danal/Card/Ready.php    (다날 API CallCredit → STARTURL 획득)
      |
  [다날 결제창]            (사용자 카드 결제)
      |
  danal/Card/CPCGI.php    (결제 결과 수신 → DongtaPointCharge UPDATE)
      |
  danal/Card/Success.php  (결제 완료 → 포인트 적립)
```

## 4. Architecture

### 4.1 결제 흐름 (Django 신규)

```
Client (Browser)
    |
    | (1) POST /api/v1/payment/danal/ready/
    |     {amount, pay_method}
    |
Django API
    |
    | (2) 다날 CPAY SDK 호출 (CallCredit)
    |     → TID, STARTURL 획득
    |
    | (3) Response: {order_id, tid, starturl}
    |
Client
    |
    | (4) 다날 결제창 리다이렉트 (STARTURL)
    |
[다날 결제 서버]
    |
    | (5) 사용자 결제 진행
    |
    | (6) Callback: POST /api/v1/payment/danal/callback/
    |     {RETURNCODE, ORDERID, TID, ...}
    |
Django API
    |
    | (7) 다날 승인 API 호출 (CallCredit APPROVE)
    |     → 최종 승인
    |
    | (8) PostgreSQL: PaymentHistory UPDATE (is_success=True)
    |     PointAccount.total_charged += amount
    |
    | (9) Celery Task: MySQL DongtaPointCharge 동기화
    |
    | (10) Response: {result, order_id, point_amount}
```

### 4.2 핵심 컴포넌트

| Component | File | Description |
|-----------|------|-------------|
| DanalClient | `apps/payment/danal/client.py` | 다날 CPAY SDK Python 래퍼 |
| DanalConfig | `apps/payment/danal/config.py` | 다날 설정 (CPID, CPPWD, URLs) |
| PaymentService | `apps/payment/services.py` | 결제 비즈니스 로직 |
| DanalReadyView | `apps/payment/views.py` | 결제 준비 (기존 수정) |
| DanalCallbackView | `apps/payment/views.py` | 결제 결과 수신 (기존 수정) |
| DanalCancelView | `apps/payment/views.py` | 결제 취소 (신규) |
| sync_payment_to_mysql | `apps/payment/tasks.py` | MySQL 이중 기록 Task |

### 4.3 다날 CPAY SDK 통신 규격

```
다날 API 엔드포인트:
- 결제 준비: https://tx-creditcard.danal.co.kr/credit/ready
- 결제 승인: https://tx-creditcard.danal.co.kr/credit/approval
- 결제 취소: https://tx-creditcard.danal.co.kr/credit/cancel

필수 파라미터:
- CPID: 가맹점 ID
- CPPWD: 가맹점 비밀번호
- AMOUNT: 결제 금액
- CURRENCY: 410 (KRW)
- ITEMNAME: 상품명
- ORDERID: 주문번호
- USERID: 사용자 ID
- RETURNURL: 결제 결과 수신 URL
- CANCELURL: 결제 취소 URL
```

- vcPayResultCode (결과 코드)
