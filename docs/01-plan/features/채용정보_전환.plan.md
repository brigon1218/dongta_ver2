> **Version**: 1.0.0
> **Author**: Team

---

## 1. Overview

### 1.1 Purpose

현재 PHP 기반으로 운영 중인 `recruit/` 모듈을 Django API 기반으로 완전히 전환하여 서비스의 성능, 유지보수성, 보안성을 향상시킨다.

### 1.2 Background

- **현황**: 채용 공고 및 이력서 데이터는 이미 `sync` 파이프라인을 통해 PostgreSQL로 동기화되고 있음.
- **문제점**: 실제 비즈니스 로직(공고 등록, 수정 등)이 여전히 PHP 코드에 의존하고 있어, 현대적인 API 기반 클라이언트 연동이 어려움.
- **목표**: PHP 코드를 제거하고 모든 채용 관련 기능을 Django REST API로 통합.

---

## 2. Scope

### 2.1 In Scope

- **기업 서비스**:
  - 회사 정보(Company) 관리 CRUD
  - 채용 공고(JobNotice) 관리 CRUD
  - 프리미엄 채용 공고 신청 및 포인트 차감 연동
- **개인 서비스**:
  - 구직자 프로필 및 이력서(JobSeeker) 관리 CRUD
- **검색 및 목록**:
  - 조건별 채용 공고 필터링 (지역, 직종, 급여 등)
  - 채용 공고 상세 조회 (조회수 카운트)
- **권한 관리**:
  - 본인 공고/이력서에 대한 수정 권한 검증 로직

### 2.2 Out of Scope

- 실시간 채팅 지원 (추후 별도 과제)
- AI 기반 채용 추천 (추후 별도 과제)
- 채용 관리 시스템(ATS) 전면 리뉴얼

## 3. Requirements

### 3.1 Functional Requirements

| ID | Requirement | Priority | Status |
|----|-------------|----------|--------|
| FR-01 | 기업용 회사 프로필 등록 및 수정 | High | Pending |
| FR-02 | 채용 공고 등록/수정/삭제 (CRUD) | High | Pending |
| FR-03 | 프리미엄 공고 전환 및 기간 설정 (포인트 연동) | High | Pending |
| FR-04 | 구직자 이력서 등록 및 공개 여부 설정 | High | Pending |
| FR-05 | 채용 공고 다중 필터 검색 (직종 JSON 처리) | High | Pending |
| FR-06 | 채용 공고 승인 프로세스 (Admin 연동) | Medium | Pending |

### 3.2 Non-Functional Requirements

- **성능**: 대량의 채용 공고 검색 시 인덱스를 활용하여 200ms 이내 응답.
- **보안**: 타인의 채용 공고나 이력서를 수정할 수 없도록 엄격한 Object-level Permission 적용.
- **정합성**: 공고 등록 및 포인트 결제 시 원자적 트랜잭션 보장.

---

## 4. Architecture

### 4.1 핵심 컴포넌트

- **Serializers**: `CompanySerializer`, `JobNoticeSerializer`, `JobSeekerSerializer`
- **Views**: `ModelViewSet`을 활용한 CRUD API 구축
- **Permissions**: `IsOwnerOrReadOnly` 커스텀 권한 클래스
- **Filters**: `django-filter`를 활용한 다중 조건 검색 지원

---

## 5. Implementation Roadmap

1. **Step 1**: Serializers 및 기초 API 구축 (CRUD)
2. **Step 2**: 검색 필터링 및 정렬 고도화
3. **Step 3**: 포인트 연동 (프리미엄 공고 신청) 로직 구현
4. **Step 4**: 권한(Permissions) 및 유효성 검증 강화
5. **Step 5**: 기존 PHP 뷰와 교체 및 최종 테스트

---

## 6. Success Criteria

- 채용 공고 등록 및 수정이 Django API를 통해 정상 작동
- 프리미엄 신청 시 포인트가 정상 차감되고 기간이 업데이트됨
- 검색 필터가 설계된 모든 조건을 정상적으로 수용함
- 일치율(Match Rate) 90% 이상 달성
