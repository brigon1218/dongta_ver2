## 1. Design Goals

1. **Integrated Schema**: 여러 테이블로 흩어진 레거시 게시판을 단일 `Post` 모델로 통합하고 `category`로 구분
2. **Role-based Access**: 공지사항(Notice)은 관리자만, 일반 게시판은 유저 권한에 따른 차등 접근 제어
3. **Recursive Comments**: 대댓글 기능을 위한 셀프 참조(Self-referencing) 구조 설계 (1단계 뎁스 권장)
4. **Denormalization for Performance**: 조회수 및 추천수를 필드로 관리하여 목록 조회 성능 최적화

## 2. Data Model Design

### 2.1 Post (게시글)

| Field | Type | Description |
|-------|------|-------------|
| **category** | CharField | NOTICE, FREE, QNA, GALLERY |
| **title** | CharField | 게시글 제목 |
| **content** | TextField | 게시글 내용 (Markdown/HTML 지원) |
| **member** | ForeignKey | 작성자 (accounts.Member) |
| **view_count** | IntegerField | 조회수 |
| **like_count** | IntegerField | 추천수 (PostLike 모델 연동) |
| **is_pinned** | BooleanField | 상단 고정 여부 (공지사항 등) |
| **is_deleted** | BooleanField | 소프트 삭제 여부 |

### 2.2 Comment (댓글)

| Field | Type | Description |
|-------|------|-------------|
| **post** | ForeignKey | 대상 게시글 |
| **member** | ForeignKey | 작성자 |
| **parent** | ForeignKey | 부모 댓글 (대댓글용, Self-referencing) |
| **content** | TextField | 댓글 내용 |

### 2.3 PostLike (추천)

- **Fields**: `post`, `member` (Unique Together로 중복 추천 방지)

## 3. API Specification

### 3.1 게시글 API (Post)

| Method | Path | Description | Permission |
|--------|------|-------------|------------|
| GET | `/api/v1/board/posts/` | 게시글 목록 (category 필터 가능) | AllowAny |
| POST | `/api/v1/board/posts/` | 게시글 작성 | IsAuthenticated (Notice는 Admin) |
| GET | `/api/v1/board/posts/:id/` | 게시글 상세 (조회수 증가) | AllowAny |
| PATCH | `/api/v1/board/posts/:id/` | 게시글 수정 | IsOwner |
| DELETE | `/api/v1/board/posts/:id/` | 게시글 삭제 (소프트 삭제) | IsOwner |
| POST | `/api/v1/board/posts/:id/like/` | 추천 토글 | IsAuthenticated |

### 3.2 댓글 API (Comment)

| Method | Path | Description | Permission |
|--------|------|-------------|------------|
| GET | `/api/v1/board/posts/:id/comments/` | 특정 글의 댓글 목록 | AllowAny |
| POST | `/api/v1/board/posts/:id/comments/` | 댓글/대댓글 작성 | IsAuthenticated |
| DELETE | `/api/v1/board/comments/:id/` | 댓글 삭제 | IsOwner |

## 4. Permission Matrix

| Category | Create | Update/Delete | List/Retrieve |
|----------|:---:|:---:|:---:|
| **NOTICE** | Staff Only | Staff Only | AllowAny |
| **FREE** | Authenticated | Owner Only | AllowAny |
| **QNA** | Authenticated | Owner/Staff | AllowAny (또는 본인글만) |

## 5. Core Logic Design

### 5.1 대댓글 구조
- `Comment` 모델의 `parent` 필드가 `null`이면 일반 댓글, 특정 ID를 가리키면 대댓글로 간주.
- 직관성을 위해 UI에서는 1단계 뎁스까지만 표현하도록 가이드.

### 5.2 추천(Like) 토글
- 이미 `PostLike` 레코드가 있으면 삭제(추천 취소), 없으면 생성(추천) 및 `Post.like_count` 업데이트.
