## 1. Design Goals

1. **Pattern Consistency**: `recruit` 모듈과 동일한 `ModelViewSet` 및 `DefaultRouter` 기반 구조 적용
2. **Granular Search**: `items` (JSONField) 내 특정 ID 포함 여부 및 지역별 통합 검색 지원
3. **Owner Protection**: 본인이 등록한 업체만 수정/삭제 가능하도록 객체 수준 권한 적용
4. **Admin Integration**: 관리자가 승인(`is_approved`)한 업체만 목록에 노출되는 필터링 로직 구현

## 2. API Specification

### 2.1 업체 관리 서비스 (Business)

| Method | Path | Description | Permission |
|--------|------|-------------|------------|
| GET | `/api/v1/business/` | 업체 목록 조회 (승인된 것만) | AllowAny |
| POST | `/api/v1/business/` | 신규 업체 등록 | IsAuthenticated |
| GET | `/api/v1/business/:id/` | 업체 상세 정보 (조회수 증가) | AllowAny |
| PATCH | `/api/v1/business/:id/` | 업체 정보 수정 | IsOwner |
| DELETE | `/api/v1/business/:id/` | 업체 정보 삭제 (소프트 삭제) | IsOwner |
| GET | `/api/v1/business/my/` | 내가 등록한 업체 목록 | IsAuthenticated |

## 3. Core Logic Design

### 3.1 검색 및 필터링 (Search & Filter)

- **통합 검색 (`q`)**: 업체명(`corp_name`), 키워드(`keywords`), 설명(`description`)에 대한 `icontains` OR 검색
- **지역 필터 (`region`)**: 주소(`address`)에 해당 문자열 포함 여부 확인
- **업종 필터 (`industry_type`)**: 정수형 업종 코드 매칭
- **품목 필터 (`item`)**: `items` (JSONField) 리스트 내에 특정 품목 ID가 포함되어 있는지 `contains` 연산자 사용
  - 예: `?item=10` -> `items__contains=10`
- **정렬**: 조회수(`view_count`) 내림차순 및 최신순(`created_at`) 내림차순

### 3.2 조회수 증가 로직

- 상세 조회(`retrieve`) 호출 시 데이터베이스의 `view_count`를 1 증가시킴.
- 중복 카운팅 방지는 향후 Redis나 쿠키를 이용해 고도화하되, 초기에는 호출 시마다 증가하는 단순 로직 적용.

## 4. Component Structure

### 4.1 Serializers
- `BusinessListSerializer`: 목록 노출용 경량 필드 구성
- `BusinessDetailSerializer`: 상세 정보 및 승인 정보 포함
- `BusinessCreateSerializer`: 등록 및 수정 시 허용할 필드 정의 (승인 상태 필드는 제외)

### 4.2 Permissions
- `apps.recruit.permissions.IsOwner` 또는 `IsOwnerOrReadOnly` 재사용 (향후 `core`로 이동 검토)

---

## 5. Implementation Order

1. **Step 1**: `recruit`에서 사용한 권한 클래스들을 `core/permissions.py`로 공통화 (권장)
2. **Step 2**: `business114/serializers.py` 리팩토링 (상세/목록/생성 분리)
3. **Step 3**: `business114/views.py`를 `BusinessViewSet`으로 전환
4. **Step 4**: `items` 필터링 및 통합 검색 로직 보완
5. **Step 5**: `urls.py`에 `DefaultRouter` 적용 및 최종 테스트
