## 2. Detailed Findings

### 2.1 Accomplishments
- **확장성 있는 댓글 구조**: 1단계 대댓글을 넘어 향후 다단계 확장이 가능한 셀프 참조 구조를 채택함.
- **안전한 데이터 처리**: 추천수 및 조회수 업데이트 시 발생할 수 있는 Race Condition을 `F` 객체와 트랜잭션을 통해 원천 차단함.
- **유연한 권한 관리**: 카테고리별로 생성 및 수정 권한을 다르게 적용하여 공지사항 보안을 강화함.

### 2.2 Deviations
- 특이사항 없음. 모든 설계 요구사항을 100% 충족함.
